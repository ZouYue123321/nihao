# 邹悦个人网站

纯静态网页，双击 `index.html` 即可打开，无需安装或构建。

## 文件结构
- `index.html`：页面骨架（不用改）
- `assets/content.js`：**网站的全部文字、图片路径、板块顺序都在这里**
- `assets/articles/<id>.js`：每篇文章的正文；`assets/articles/<id>/`：正文里的图片
- `assets/app.js`：渲染、文章阅读器和编辑模式（不用改）
- `assets/upload.js`：编辑模式里的「上传文章」和「导出更新包」（只在 `?edit=1` 时加载）
- `assets/vendor/`：上传功能用到的开源库（mammoth 读 Word，BSD-2；marked 读 Markdown，MIT；fflate 打 zip，MIT），协议文件在同一文件夹
- `assets/style.css`：样式
- `assets/hero-bg.js`：首屏流动丝带背景动画（原创 Canvas 动画；系统开启「减少动态效果」时只显示静态画面，滚出首屏或切到后台会暂停）
- `assets/logo/`：MelodyZ 标志（`melodyz-white.svg` 用于黑底，`melodyz-black.svg` 用于白底）、网站图标 `favicon.svg` / `favicon-32.png` / `apple-touch-icon.png`
- `screenshots/`：预览截图（发布时可删）

## 编辑指南

### 方法一：在网页上直接改（推荐）
1. 用浏览器打开 `index.html`，在地址栏末尾加上 `?edit=1`，回车。  
   例：`file:///Users/你/zouyue-site/index.html?edit=1`（发布后是 `https://melodyzpm.com/?edit=1`）
2. 底部出现黄色「编辑模式」工具条：
   - **改文字**：直接点页面上的文字修改。
   - **增删和排序**：每一项右上角有 ↑ ↓ ✕；每组下方有「＋ 添加一项」（适用于观点、文章、实验、成长记录、标签等）；产品笔记下方有「＋ 添加拆解」「＋ 添加测评」两个按钮。
   - **产品笔记**：卡片只显示类型、名称、定位、使用时间和「我想回答」；点卡片上的「编辑详情 →」打开详情页，在里面改全部字段（使用时间、官网、拆解/测评字段、标签用逗号分隔、配图）和全文（空一行即分段）。卡片右上角 ✕ 删除。卡片按使用时间（如 2025.03）从新到旧自动排序，每页 6 张。
   - **换图片**：点击带黄色虚线框的图片，选择本地图片即可（左上角 Logo 也可以这样换）。
   - **改文章正文**：点文章卡片的封面或「阅读全文」打开文章，正文可直接修改；点右上角「导出本文 .js」，下载后替换 `assets/articles/<id>.js`。
   - **板块设置**：调整板块顺序、显示或隐藏、黑底或白底。
3. 修改会自动保存在**当前浏览器**里，别人看不到。
4. 改好后点「**导出更新包**」，会下载一个 zip，里面是最新的 `content.js` 和新文章的正文、图片，文件夹结构和网站一样（放法见下面「上传文章」）。只改了文字、没动文章时，也可以点「只导出 content.js」，用下载的文件替换 `assets/content.js`。
5. 「重置」会丢弃浏览器里的修改，恢复成当前 content.js 的内容。

> 注意：导出的 content.js 不带原来的中文注释，但不影响使用。换的图片会以文字编码的形式（data URL）存进 content.js，图片太大会让文件变大，建议先压缩到 500KB 以内。也可以把图片放进 `assets/`，在 content.js 里填路径。普通访客打开网址时不会看到编辑模式。

### 方法二：用文本编辑器改 content.js
用任意文本编辑器打开 `assets/content.js`，只改引号里的文字，保留逗号和括号。文件里每一块都有中文注释。

### 文章列表（自动排序 + 分页）
- 文章按 `date` 自动从新到旧排列，`articles` 里的书写顺序无所谓；日期请写成 `2026.10.11` 这种格式。
- 每页 5 篇，超过 5 篇自动出现页码（改每页数量：`assets/app.js` 里的 `PER=5`）。
- 编辑模式里文章只有 ✕ 删除，没有 ↑ ↓：改日期后点别处，列表会自动重排。新加的文章默认是今天的日期，排在第一位。
- 编辑模式里点每行右侧「阅读 →」打开正文。
- 没有封面图的文章（`cover: ""`）会显示黑底文字封面，文字取 `coverText`（如 `"GPT-5"`），没填就取标题前几个字。
- 旧的浏览器草稿里没有的新文章，打开编辑模式时会自动补进去；在草稿里删掉的文章不会被加回。

### 上传文章（推荐）
1. 打开 `index.html?edit=1`，在文章列表下面点「**⬆ 上传文章**」。
2. 填标题、日期（默认今天，格式 `2026.10.17`）；摘要可不填，会自动取正文前 60 字；封面可选，会自动压缩到 500KB 以内。
3. 正文二选一：
   - 点「从文件导入」，选 Word（.docx）、Markdown（.md）、纯文本（.txt）或网页（.html）文件，也可以把文件直接拖进弹窗；
   - 或者在公众号/网页里全选复制文章，粘贴到正文框里（保留段落、小标题、加粗、图片，自动去掉脚本和样式）。
4. 点「保存文章」，列表里立刻按日期排好，点「阅读 →」就能看。此时只存在**这个浏览器**里。
5. 每篇文章右上角有「编辑」（改标题、日期、封面、正文）和「✕」（删除）。
6. 点底部「**导出更新包**」，下载 `zouyue-site-update-日期.zip`，三种放法任选：
   - 把 zip 发给 Grok Bot，帮你放好并发布；
   - 解压后把里面 `assets/content.js` 拖进网站的 `assets/`，再把里面 `assets/articles/` 的所有东西全选拖进网站的 `assets/articles/`，重名选「替换」（**不要整个 assets 文件夹替换**）；
   - 终端：`ditto ~/Downloads/zouyue-site-update-日期 ~/Downloads/zouyue-site`（自动合并，不删文件）。
7. 放好、确认网站正常后，点「重置」清掉浏览器草稿。

> 正文和图片存在浏览器的 IndexedDB 里，换浏览器或清理浏览器数据会丢，所以写完尽快导出。Word 里的大图会压缩到约 400KB 以内。公众号图片如果对方网站不允许转存，会保留原图链接（原文删图后会失效），这种情况把 zip 发给我，我可以把图下载到本地。

### 手动新增一篇文章
1. 在编辑模式里给文章「＋ 添加一项」（或在 content.js 的 `articles` 里复制一项），记下它的 `id`。
2. 复制任意一个 `assets/articles/xxx.js`，改名为 `<id>.js`，把第二行里的 id 换成新的，然后把反引号之间的内容换成正文 HTML（`<p>段落</p>`、`<h3>小标题</h3>`、`<strong>加粗</strong>`、`<img src="assets/articles/<id>/01.jpg">`）。

### 浏览器草稿与 content.js 更新
编辑模式会记住每份草稿是基于哪个版本的 content.js。以后 content.js 里的「首屏一句话、关于我、产品笔记、成长记录」更新时：
- 你在浏览器草稿里**没改过**这一项 → 打开 `?edit=1` 时自动换成新内容；
- 你**改过**这一项 → 底部出现提示，选「用最新内容」（只替换提示里列出的几项，其他修改不动）或「保留我的修改」。选之前提示每次打开都会出现，不会自动丢掉你的修改。
